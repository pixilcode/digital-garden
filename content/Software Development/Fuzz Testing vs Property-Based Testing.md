**Link: [Fuzz Testing vs Property-Based Testing](https://www.bjaress.com/posts/2021-07-03/fuzz-testing-vs-property-based-testing.html)**

Though often they are treated as the same thing, there is actually a difference between fuzz testing and property-based testing. Fuzz testing "expects that some disaster never occurs on every input", while property-based testing "expects that the output has some desirable property for some broad range of input".
