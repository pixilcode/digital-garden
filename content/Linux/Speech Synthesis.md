[You can use `spd-say` to test if your speech dispatcher is working.](https://support.mozilla.org/en-US/kb/speechd-setup?as=u&utm_source=inproduct) If you run `spd-say hi`, it should say "hi". If it says something like "This is the dummy output module. It seems your speech-dispatcher is working, but none...", then [you need to install an output module like espeakup](https://bbs.archlinux.org/viewtopic.php?id=268780).
