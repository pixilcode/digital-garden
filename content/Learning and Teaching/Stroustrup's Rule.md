**Link: [Stroustrup's Rule](https://buttondown.com/hillelwayne/archive/stroustrups-rule/)**

When you are a beginner, explicit is better than implicit. When you are an expert, implicit is better than explicit. When you are teaching, it is better to avoid implicit syntax or ideas.

## Personal Opinion

Based on this article, it sounds like for things like software, explicit takes precedence over implicit, since more often than not, someone reading the code is a beginner in the codebase. By default, there exist more beginners than experts in any given area, so optimizing code for beginners is better. Plus, an expert may lose some expertise after spending time away from the code. This is similar in nature to the saying "optimize code for reading, not writing".

Obviously, there's a balance to this. Too much explicitness can become boilerplate, and it can create information overload for a beginner.
