**Link: [Yes, and...](https://htmx.org/essays/yes-and/)**

AI doesn't take away the role of a programmer—it modifies it. Software developers in today's world need to worry more about _problem solving_ and _controlling complexity_ rather than _writing code_.

However, AI can be detrimental to learning. Having it write all the code for you can take away learning opportunities. Instead, you should have it act like a TA for you (see this [`AGENTS.md`](https://gist.github.com/1cg/a6c6f2276a1fe5ee172282580a44a7ac) file for how this might work).
