**Link: [Jam Programming Language](https://rapha.land/jam-programming-language/)**

Jam is a programming language that is intended to mix Rust's safety with Zig's simplicity. In Jam, there are no "first-class references", which means that there are no lifetimes. Everything gets dropped at the end of the scope. The goal is to create a language that competes with Rust or Zig.
