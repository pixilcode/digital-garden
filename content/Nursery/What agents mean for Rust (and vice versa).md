**Link: [What agents mean for Rust (and vice versa)](https://smallcultfollowing.com/babysteps/blog/2026/10/14/agentic-dev-and-rust/)**

Rust is a great language for agentic development. It provides lots of guardrails with its type system, and it provides easy wins for performance. This static feedback is why it is so useful for AI.

However, there is still room for improvement. If Rust added ways to prove code correctness, especially in terms of `unsafe` code, that would improve the experience even more! Tools like [Verus](https://github.com/verus-lang/verus), [Creusot](https://creusot.rs/), [Aeneas](https://aeneasverif.github.io/), and [Kani](https://github.com/model-checking/kani) make this possible.
