**Link: [Rewriting the world in Rust](https://bitfieldconsulting.com/posts/rewrite-in-rust)**

Rewriting software in Rust is a more difficult task than one might think. It's more than just a syntactic translation. Rust moves more semantics to the syntax, so a translation needs to capture that. Also, rewriting in Rust often involves rethinking the architecture.

Instead, C++ code should be rewritten to a more Rust-like structure _before_ trying to translate it.

How does [[content/Research/&inator/index|&inator]] play into this? What role does it play if a simple translation isn't sufficient?
